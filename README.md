# 麻将 · Offline Mahjong

一个完全离线的四人麻将游戏：**纯 Python 标准库引擎 + 本地 HTTP 服务 + 浏览器 Canvas 前端**。
零依赖（除训练脚手架需要 numpy）、纯 CPU 实时运行、Windows / macOS / Linux 通吃。

```
python server.py --port 8080
```

然后浏览器打开 <http://127.0.0.1:8080> 即可开玩。断网可用。

---

## 功能一览

| 维度 | 内容 |
|---|---|
| 三种规则 | 经典推倒胡（136 张·吃碰杠·一炮多响）／ 四川血战（108 张·定缺·刮风下雨·查大叫·花猪罚）／ 广东鸡平胡（136 张·可买马 0-4 匹） |
| 三档难度 | 易（向听贪心 + 故意犯错）／ 中（进张 + 危险度防守 + 牌型价值）／ 难（**蒙特卡洛前瞻**：对每个候选弃牌抽样对手手牌与牌墙、快推演 6 步、约 400 次模拟/决策，约 1.4 秒/手） |
| 发牌随机性 | 系统级加密随机 `secrets.SystemRandom` 洗牌；可传 `seed` 复现同一手牌用于复盘 |
| 信息不可见 | 服务端 `public_snapshot()` 只向客户端下发他人手牌**张数**，绝不下发他人手牌内容；断点调试可证 |
| 界面 | Canvas 伪 3D 一体式牌面（牌框与填充同一几何整体变换）、顶灯暖光、光晕、牌墙、扇形弃牌、回合光圈、庄家/定缺/听牌徽章、胜利结算弹层、音效 |
| 离线 | 全本地 HTTP 服务，无任何外网请求 |

## 快速开始

```powershell
# 1) 启动（Windows PowerShell 或任意终端）
python server.py --port 8080 --no-open

# 2) 浏览器访问
#     http://127.0.0.1:8080
#     （不带 --no-open 会自动打开浏览器）

# 3) 自检
python tests.py          # 55 项引擎测试
python _js_smoke.js 需要 node    # 前端渲染冒烟（可选）
```

命令行参数：

```
python server.py [--port 8080] [--host 127.0.0.1] [--no-open] [--policy train/samples/policy.json]
```

`--policy` 注入训练好的弃牌策略（见 `train/README.md`）。

## 玩法要点

- 你的座位永远是「你」（下方，庄家徽章显示风位），其余为电脑·南／西／北。
- 轮到你时点击手牌打出；`？` 按钮内有完整规则说明。
- 四川规则开局需先**定缺**：选一门为缺门。**缺门牌必须优先打光**（摸到缺门牌必须打，哪怕点炮），缺门未清空前不能出其他花色；胡牌时手牌不得含缺门。
- 广东规则可选买马（0-4 匹）：和牌后从牌墙尾摸马，按牌面方位结算（1/5/9 及中发白→庄，2/6→南，3/7→西，4/8→北）。
- 设置开关：音效、自动过牌（有胡以外的吃碰选择时自动放过）、听牌提示（可胡牌高亮）。

## AI 三档是怎么做的

| 档位 | 决策机制 | 说明 |
|---|---|---|
| 易 | 向听贪心：选使向听数最小、进张最多的弃牌；15% 概率故意乱打 | 新手陪练，会犯错 |
| 中 | 进张数 + 牌型形状价值 + 危险度折叠（对手听牌估计高时避开危险牌） | 正常水平，偶有防守过头 |
| 难 | 蒙特卡洛：对每个合法弃牌，抽样对手手牌与剩余牌墙，用快策略推演 6 步，按胡牌概率/点炮风险选择 | “看到未来”式打法，接近高手；约 1.4 秒/决策 |

**关于“高手的经验”**：蒙特卡洛天然覆盖了“牌型、进张、防守”的大部分经验性判断（它以期望胜率直接做选择）。经验中纯靠长期牌谱统计的部分（如特定局面该留哪张、读对手习惯）难以靠前瞻获得——这正是 `train/` 强化学习脚手架存在的意义：用自对弈从牌谱中学习这些频率型经验，训练产物通过 `--policy` 注入 hard AI。详见 `train/README.md`。

**AI 只使用公共信息 + 自己的手牌**，绝不读取其他玩家手牌（源码可查：`ai.py` 只访问 `game._p(q).discards / melds` 与自己的 `hand`）。

## 常见问题

- **服务起不来 / 端口被占**：换端口 `python server.py --port 8090`。
- **想复盘某手牌**：开始界面没有种子输入时可在 URL 加 `?seed=123`，或直接 POST `/api/game/new` 带 `seed`。
- **hard 档每手约 1 秒**：这是蒙特卡洛的代价；介意可改 `mahjong/ai.py` 顶部 `MC_BUDGET`（秒）/`MC_MAX_ITER`。
- **想训练更强的 AI**：`cd train && python ppo_train.py ...`，见 `train/README.md`。
